# Google Flow Team Studio & Approval Hub

ระบบศูนย์กลางบริหารจัดการกระบวนการผลิตสื่อ AI ร่วมกันของทีมงาน 5 ท่าน ออกแบบมาเพื่อเชื่อมต่อกระบวนการคิดคอนเซปต์, การเขียนบทพากย์, การปรับแต่ง AI Prompts (Google Veo / Imagen), ระบบคิวตรวจอนุมัติ (Review Gatekeeper), และการส่งออกผลงานไปยัง Google Flow Studio ได้อย่างมีประสิทธิภาพสูงสุด

---

## 👥 โครงสร้างบทบาทและหน้าที่ของทีมงาน 5 ท่าน

| สมาชิก | ตำแหน่งในระบบ | สิทธิ์และความรับผิดชอบหลัก |
| :--- | :--- | :--- |
| **คุณกรองเกียรติ (ผม)** | `Admin & Executive Producer` | ดูแลและควบคุมระบบทั้งหมด มีสิทธิ์สูงสุดในการสร้าง แก้ไข อนุมัติ ส่งออก และจัดสรรโควตางาน |
| **คุณบอส** | `Executive Approver & Manager` | ประตูตรวจอนุมัติขั้นสุดท้าย (Approval Gatekeeper) อนุมัติคลิป/ขอแก้ไข ให้ความเห็น กำกับ KPI และคลังสำรอง |
| **คุณลีน** | `Nutrition Strategist & Brand Lead` | วางแกนเนื้อหาโภชนาการช่อง `leanbybenz` ตรวจสอบข้อความให้ถูกต้องตามหลักการแพทย์/อย. และนโยบายชุมชน (ห้ามเคลมเกินจริง) |
| **คุณเก๋** | `Creative Director & Host Persona` | ออกแบบ Storyboard ทีละฉาก ควบคุม Mood & Tone เขียนบทพากย์เสียงคุณเก๋ (`th-TH-PremwadeeNeural` `--rate=-15%`) |
| **คุณคอด** | `Lead Developer & AI Prompt Engineer` | วิศวกร AI ปรับจูน Prompt ภาษาอังกฤษให้ Google Veo / Imagen สร้างภาพและวิดีโอคมชัดระดับ 4K ดูแลระบบ Automation และ MCP |

## 🚀 ฟังก์ชันเด่นของระบบ

1. **Role Switcher (สลับผู้ใช้งานได้ทันที):** เมนูด้านขวาบนสามารถสลับโปรไฟล์เพื่อจำลองการทำงานของแต่ละท่านตามบทบาทจริง
2. **Review & Approval Gate (คิวตรวจอนุมัติ):** ตารางแสดงรายการผลงานที่มี sticky header ตรึงหัวตาราง ไม่มีแถบเลื่อนแนวนอนกวนใจ พร้อมปุ่ม **✓ อนุมัติ** หรือ **✕ ขอแก้ไข** เฉพาะสำหรับคุณบอสและ Admin
3. **Review Buffer Monitor (คลังสำรอง 5-7 คลิป):** แถบวัดความพร้อมของคลิปสำรองตามระเบียบ leanbybenz เพื่อให้ทีมมีคอนเทนต์พร้อมโพสต์ต่อเนื่อง
4. **Storyboard & Scene Builder:** ระบบออกแบบฉากวิดีโอ 9:16 ที่แยก Visual Prompt สำหรับ Google Veo และ Voiceover สำหรับเสียงคุณเก๋ พร้อมปุ่มคัดลอกใน 1 คลิก
5. **Prompt Engineering Presets:** คลังพร้อมท์สำเร็จรูปที่ปรับแต่งค่ามาตรวัดความชัด มิติแสงสตูดิโอ และการเคลื่อนไหวของกล้อง ให้พร้อมนำไปวางใน Google Flow ได้ทันที
6. **Direct Google Flow Integration:** มีปุ่มลิงก์ตรงไปยัง `labs.google/flow` พร้อมคัดลอก Prompt ทั้งหมดของโปรเจกต์ลงในคลิปบอร์ด
